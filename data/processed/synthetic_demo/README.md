# ⚠️ SYNTHETIC DATA — NOT REAL BANGLADESH OBSERVATIONS

The file in this folder (`synthetic_agroclimate_demo.csv`, generated by
`scripts/generate_synthetic_demo.py`) is entirely randomly generated.

- District and crop **names** are real Bangladesh districts/crops (for schema realism).
- Every **value** (area, production, yield, rainfall, temperature, humidity) is synthetic.
- The relationship baked into the synthetic yield formula is a simple toy function written to give the pipeline code something non-trivial to fit — it is not a model of real agronomy.

**This data exists for exactly one purpose:** proving that the ingestion → validation → cleaning → feature engineering → modelling → evaluation → governance-check pipeline in `src/` runs correctly end-to-end, without needing network access to a real dataset.

Any metric computed from this file:
- is labelled `"DEMONSTRATION ONLY — NOT EMPIRICAL EVIDENCE"` everywhere it's reported (enforced in code — see `src/governance/checks.py::check_synthetic_label_present`)
- must never be cited as evidence about real Bangladesh agriculture, climate, or yield patterns
- must never inform any policy conclusion

To replace this with real data, see `scripts/fetch_real_data.py` and `docs/data-provenance/provenance-register.md`.
