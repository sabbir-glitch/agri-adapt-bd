# Data Provenance Register

> **Independent open-source research project.** This repository and its contents are not affiliated with, reviewed by, or endorsed by any organization. Nothing here should be read as an institutional endorsement of any kind.

Every dataset considered for this project is logged here against a four-level evidence status, used consistently throughout this repository:

| Status | Meaning |
|---|---|
| **DOCUMENTED** | A source's own description/metadata page states this (e.g. "4,607 records, 33 features") — I read that claim, I did not independently recompute or verify it. |
| **EXPECTED** | This project's code anticipates a field/value based on a DOCUMENTED description — not yet checked against an actual file. |
| **OBSERVED** | An actual data file was opened and inspected in this project (row counts, column names, value ranges directly read from the file itself). |
| **VERIFIED** | OBSERVED, plus the source and licence were independently cross-checked. The highest bar — reserved for claims this project can fully stand behind. |

The evidence status applies to each specific claim, not merely to whether a website exists. Candidate sources #1–#9 were assessed mainly from descriptions/metadata; their actual data files were not used in this project. Source #11 is different: both agricultural CSV files were opened, their columns and rows were inspected, and they were used in an exploratory run. **Source #11 remains OBSERVED, not fully VERIFIED**, because the exact lineage of the values, source units, rainfall aggregation and dataset-specific redistribution rights remain unresolved. The real run is therefore labelled **REAL DATA, UNVALIDATED**.

Access dates are recorded per entry where available. The jute and wheat files were retrieved on 2026-10-11; the real-data experiment was rerun on 2026-10-12.

## What this means for the rest of the repository

- **One real dataset (#11) has been opened and modelled**; candidates #1–#5 and #7–#9 were file-access-blocked or not retrieved and were **not** observed (#6 is a reference-only project, not a data source). Real-data results come only from #11 and are labelled **real, unvalidated**; they are not field-validated and the exact lineage from the upstream's cited references (BBS "45 years Major Crops"; data.gov.bd daily rainfall) to each value is unresolved.
- Real and synthetic results are kept separate: synthetic rows carry `status=demonstration_only`, real rows `real_unvalidated`, in `outputs/reports/experiment-registry.csv`.
- The canonical model schema was initially informed by documented candidate-source descriptions. The #11 adapter was subsequently mapped against an OBSERVED jute/wheat CSV schema; other candidate-source schemas remain unobserved.
- `scripts/fetch_real_data.py` can attempt the blocked downloads from a machine with normal internet access.
- Any number derived from the synthetic dataset carries the label **"DEMONSTRATION ONLY — NOT EMPIRICAL EVIDENCE."** No exceptions.

## Still open (explicitly unresolved, not silently assumed)

- Source #11: exact lineage of each value from the upstream-cited references, the units of the area/production columns, what `Rainfall in MM` aggregates, and dataset-specific redistribution rights (the upstream repository's MIT LICENSE is not a dataset-specific rights statement).
- Exact licence text for AgriClimateBD, SPAS-Dataset-BD, and the data.gov.bd Climate Database — marked LICENSE REQUIRES REVIEW until a primary source page is actually opened.
- Whether AgriClimateBD is at Mendeley version `/1` or `/2` — different sources referenced different version suffixes; needs reconciling against the live page before citing a specific version number.
- Whether BBS data is available as structured machine-readable files (CSV/API) or only as PDF statistical yearbooks/tables — this changes how `src/data/ingestion.py` would need to parse it.
