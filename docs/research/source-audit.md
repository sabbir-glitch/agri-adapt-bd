# Source and Claims Audit — v0.1.0

This audit describes the released repository state. It is a code/documentation consistency check, not an independent scientific validation of the source data or model.

## Evidence status

- **Synthetic demonstration:** generated by `scripts/generate_synthetic_demo.py` and evaluated by `scripts/run_pipeline.py --source synthetic`. These results are demonstration-only and are not empirical evidence about Bangladesh agriculture.
- **Real-data exploratory run:** `scripts/run_real_pipeline.py` was run against the jute/wheat CSV files downloaded from the upstream GitHub repository. Their columns and row values were observed; the adapter and real pipeline were executed. The files are intentionally excluded from the release archive and can be fetched through `scripts/fetch_real_data.py --source sajidahmed12`.
- **Not fully verified:** the upstream README references a BBS “45 years Major Crops” report and a data.gov.bd daily rainfall dataset, but the exact lineage from those references to every CSV value and transformation has not been established. Source units, the meaning of “Rainfall in MM,” and dataset-specific redistribution rights remain unresolved. Do not present the data as officially verified statistics.
- **No separate climate dataset:** the real model uses the agricultural source's own rainfall field, whose aggregation is undocumented. Temperature and humidity are absent from those files. No district/year climate join has been performed.

## Claims reviewed

| Area | Current defensible statement | Boundary / unresolved point |
|---|---|---|
| Data provenance | The actual jute/wheat files were opened and used in an exploratory run. | Primary-source lineage, units and rainfall semantics remain unresolved. |
| Model results | Reported metrics were computed by the real-data pipeline on a chronological held-out test period. | One split and seed; no field validation; test composition is crop-imbalanced; results are exploratory. |
| Prediction intervals | Split-conformal intervals are calibrated on the calibration split and empirical coverage is measured on the later test split. | Temporal distribution shift can invalidate exchangeability assumptions; coverage is not guaranteed for future years. |
| Climate | The agricultural table includes a field labelled `Rainfall in MM`. | Its temporal/spatial aggregation is unknown; no separate climate dataset or temperature/humidity input is integrated. |
| Dashboard | Synthetic mode is programmatically tested; real mode requires a canonical-schema CSV upload. | Real mode is not wired to the jute/wheat experiment outputs; no browser click-through test was performed. |
| CI | Default and manual workflows are configured and their YAML parses. | GitHub-hosted Actions have not been executed in this release process. |
| User/field evidence | No farmer, field-officer, or agronomist testing is claimed. | No field validation or impact evaluation was performed. |

## Verification record

- The release test suite contains 40 tests. It passed in the package author's reported run and in a separate package review run.
- The synthetic pipeline runs from the repository and emits a machine-generated run log and experiment-registry entry. Exact floating-point metrics can vary slightly across dependency versions because `requirements.txt` gives minimum versions rather than a fully locked environment.
- The real-data outputs in `outputs/reports/` are from the packaged real-data run. The raw CSVs are not bundled; a fresh real run requires successful retrieval and checksum verification.
- This audit did not establish model validity for operational agricultural advice, causal effects, national representativeness or farmer benefit.

## Publication rule

Keep **SYNTHETIC DEMONSTRATION** and **REAL DATA, UNVALIDATED** distinct. Any future claim should be supported by the exact files, transformations, provenance and experiments behind it. This repository is a research/engineering prototype, not a field-validated agronomic advisory system.
